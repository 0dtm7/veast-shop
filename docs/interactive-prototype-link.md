## Локальный кликабельный прототип

После запуска проекта также можно открыть локальный HTML-прототип:

`http://localhost:3000/prototype.html`

Он показывает основной пользовательский путь:

Главная → Каталог → Карточка товара → Корзина → Checkout → Подтверждение.

## Файл для импорта / резервная копия

В проекте также сохранён Figma-ready SVG-файл:

`figma/VEAST_figma_import.svg`

Копия лежит здесь:

`docs/figma/VEAST_figma_import.svg`

Этот файл можно использовать как резервную заготовку, если нужно быстро восстановить прототип или перенести его в другой Figma-файл.
