# Дневник разработчика VEAST

## Запись 1. Выбор идеи
Команда выбрала интернет-магазин одежды VEAST. У проекта понятная коммерческая цель: продажа товаров через оформление заказа. Формат магазина подходит под требования дисциплин, потому что позволяет реализовать каталог, карточку товара, корзину, оформление заказа, личный кабинет, backend и тестирование.

## Запись 2. Распределение ролей
- UX-аналитик: целевая аудитория, персонажи, сценарии, информационная архитектура.
- UI-дизайнер: визуальная система, сетка, компоненты, карточки товаров.
- Frontend-разработчик: HTML/CSS/JS, адаптивность, интерактивные элементы.
- Backend-разработчик: Node.js сервер, API заказов, сохранение данных.
- Менеджер/тестировщик: план работ, дневник, тестирование, подготовка к защите.

## Запись 3. Анализ пользователей
Определили аудиторию 16–28 лет. Пользователи часто заходят с мобильных устройств, хотят быстро понять ассортимент, цену, размер и условия доставки. Поэтому сайт должен быть понятным, быстрым и коммерчески направленным.

## Запись 4. Персонажи и сценарии
Подготовлены три персонажа: студент с ограниченным бюджетом, пользовательница, ориентированная на эстетику и избранное, и молодой специалист, сравнивающий товары. На основе персонажей составлен ключевой путь: главная → каталог → карточка → корзина → checkout.

## Запись 5. Информационная архитектура
Выбрана гибридная структура. Каталог организован по категориям, карточка товара раскрывается линейно, а избранное создают дополнительные связи.

## Запись 6. Бумажное проектирование
Для бумажного прототипа подготовлен набор экранов: главная, каталог, карточка товара, корзина, оформление, подтверждение, личный кабинет, пустое состояние и ошибка 404. Коллаж должен показать путь покупки.

## Запись 7. UI-решения
Принята минималистичная визуальная система: белый фон, чёрный текст, тонкие линии, строгая сетка, акцент на карточки товаров. Это помогает коммерческой цели, потому что пользователь не отвлекается от выбора товара.

## Запись 8. Frontend-разработка
Сделаны страницы сайта, каталог, фильтры, сортировка, поиск, карточки товаров, корзина, избранное, личный кабинет, контакты и политика. Состояние корзины и списков сохраняется в localStorage.

## Запись 9. Backend-разработка
Добавлен сервер на Node.js. Реализованы endpoint-ы `/api/products`, `/api/orders`, `/api/feedback`, `/api/health`. Заказы и обращения сохраняются в JSON-файлы. Добавлена базовая валидация.

## Запись 10. Тестирование
Подготовлен план тестирования для 5 пользователей. После проверки нужно заполнить таблицу результатов и указать исправления.

## Запись 11. Подготовка к защите
В проект добавлены дизайн-документ, карта сайта, план тестирования, описание бумажного прототипа, README и страница `project.html` для демонстрации логики продукта.

## Запись 12. Следующий этап
После утверждения структуры нужно разработать финальные дизайны одежды и заменить временные изображения товаров на полноценные mockup-карточки.
