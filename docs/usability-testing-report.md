# Отчёт по юзабилити-тестированию VEAST

## Цель
Проверить, может ли пользователь без подсказок выполнить главное коммерческое действие: найти товар, добавить его в корзину и оформить заказ.

## Правильный формат задания
Формулировка должна быть целью пользователя, а не инструкцией. Например: «Вы хотите купить худи на каждый день. Найдите подходящий вариант и оформите заказ».

## Респонденты
Минимум 5 человек из целевой аудитории 16–28 лет.

## Тестовые задания
1. Вы хотите купить худи на каждый день. Найдите подходящий вариант и добавьте его в корзину.
2. Вы хотите купить вещь из новой коллекции. Найдите товар, посмотрите фото и состав.
3. Вы хотите вернуться к товару позже. Сохраните товар в избранное.
4. Вы хотите оформить заказ и указать доставку. Пройдите путь до страницы подтверждения.
5. Вы зашли с телефона. Откройте каталог, найдите товар и проверьте корзину.
