# Бумажное проектирование VEAST

Бумажное проектирование вынесено в папку:

`docs/paper-prototype/`

Внутри находятся листы на миллиметровой сетке:

- `01-home.png` — главная страница
- `02-catalog.png` — каталог
- `03-product.png` — карточка товара
- `04-cart.png` — корзина
- `05-checkout.png` — оформление заказа
- `06-thanks.png` — подтверждение
- `07-account-favorites.png` — кабинет / избранное
- `08-404-empty.png` — ошибка / пустое состояние
- `09-user-flow-collage.png` — коллаж пользовательского пути

## Пользовательский путь в коллаже

Главная → Каталог → Карточка товара → Корзина → Checkout → Подтверждение заказа.

## Важно

Эти изображения являются цифровой заготовкой бумажного прототипа. Если преподаватель требует именно физические фотографии, нужно распечатать или перерисовать экраны на миллиметровой бумаге, разложить путь пользователя и сфотографировать результат.
