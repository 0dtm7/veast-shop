# Интерактивный прототип VEAST

## Ссылка на Figma

Figma-прототип VEAST добавлен в проект:

https://www.figma.com/design/u3CLNOluVqsUsrbXidVjXQ/Untitled?node-id=1-15&t=k76jAOBQJ0oYwSoI-1

Эта ссылка используется для сдачи по PDF-заданию и демонстрирует интерактивный сценарий коммерческого сайта.

## Что показано в Figma
PDF-задание требует интерактивный прототип: карту экранов, компоненты, варианты кнопок и форм, состояния элементов, минимум один полный коммерческий сценарий от входа на сайт до целевого действия, а также desktop и mobile. Для VEAST основной сценарий — оформление заказа.

## Карта экранов для Figma
1. Главная desktop
2. Главная mobile
3. Каталог desktop
4. Каталог mobile
5. Карточка товара desktop
6. Карточка товара mobile
7. Корзина desktop/mobile
8. Checkout desktop/mobile
9. Thanks / подтверждение
10. Избранное
11. Личный кабинет
12. Контакты
13. 404 / пустое состояние

## Основной кликабельный сценарий
Главная → Каталог → Карточка товара → Добавить в корзину → Корзина → Оформление заказа → Подтверждение.

## Компоненты
- Header: логотип, меню, поиск, иконки избранного и корзины.
- Product card: изображение, бейджи, название, цена, размеры, CTA.
- Filter panel: категория, цена, размер, цвет, наличие.
- Form field: normal, focus, error, success.
- Button: primary, ghost, disabled.
- Empty state: пустая корзина, пустое избранное, ничего не найдено.
- Footer: контакты, оферта, политика, Telegram.

## Состояния
- Hover карточки товара.
- Активный размер.
- Ошибка обязательного поля.
- Пустая корзина.
- Успешное оформление заказа.
- Недоступный backend / fallback.

## Резервный локальный прототип
В проекте также есть локальный кликабельный прототип: `prototype.html`.
Он нужен как резервная демонстрация, если Figma не откроется из-за доступа к интернету.
