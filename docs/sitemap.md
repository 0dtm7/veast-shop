# Карта сайта VEAST

```text
Главная / index.html
├── Каталог / catalog.html
│   ├── Категория: худи
│   ├── Категория: футболки
│   ├── Категория: лонгсливы
│   ├── Категория: верхняя одежда
│   ├── Категория: брюки
│   ├── Категория: аксессуары
│   └── Карточка товара / product.html?id=...
│       ├── Фото / галерея
│       ├── Цена / размеры / наличие
│       ├── Описание / состав / уход
│       └── CTA: добавить в корзину
├── Избранное / favorites.html
├── Корзина / cart.html
│   └── Оформление заказа / checkout.html
│       └── Подтверждение / thanks.html
├── Личный кабинет / account.html
├── Контакты / contacts.html
│   └── Форма обратной связи
├── Оферта и политика конфиденциальности / privacy.html
├── Проект / project.html
└── Ошибка / 404.html
```

## Тип структуры
Гибридная структура:
- древовидная — для каталога и категорий;
- линейная — для карточки товара и checkout-пути;
- сетевая — для избранного, рекомендаций и связанных переходов.

## Схема основного коммерческого пути
Главная → Каталог → Карточка товара → Корзина → Оформление заказа → Подтверждение.

## Принцип трёх кликов
- Каталог доступен с любой страницы через header.
- Корзина доступна с любой страницы через header.
- Контакты, оферта и политика доступны через footer.
- Оформление заказа доступно из корзины одним кликом.
