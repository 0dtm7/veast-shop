## Как сделать именно Figma-ссылку

1. Открой Figma в браузере или приложении.
2. Создай новый Design file.
3. Перетащи файл `VEAST_figma_import.svg` на холст Figma.
4. Разгруппируй элементы при необходимости: Right click → Ungroup.
5. В Prototype mode свяжи экраны по цепочке:
   Home → Catalog → Product → Cart → Checkout → Thanks.
6. Нажми Share → Copy link.
7. Вставь ссылку в Moodle-дневник и в файл `docs/interactive-prototype-link.md`.
