# Бумажное проектирование VEAST

В папке лежат цифровые листы бумажного прототипа на миллиметровой сетке:

1. `01-home.png` — главная страница
2. `02-catalog.png` — каталог
3. `03-product.png` — карточка товара
4. `04-cart.png` — корзина
5. `05-checkout.png` — оформление заказа
6. `06-thanks.png` — подтверждение заказа
7. `07-account-favorites.png` — личный кабинет / избранное
8. `08-404-empty.png` — ошибка / пустое состояние
9. `09-user-flow-collage.png` — коллаж пользовательского пути

Важно: это цифровая заготовка бумажного прототипа. Если преподаватель требует именно физические фото, эти листы нужно распечатать или перерисовать на миллиметровой бумаге, вырезать экраны, разложить пользовательский путь и сфотографировать.
