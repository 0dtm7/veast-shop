# VEAST Telegram Mini App v7

Что добавлено:

- История заказов подтягивается из Neon по Telegram ID через `/api/telegram/orders?chatId=...`.
- Заказы, сделанные с телефона, должны появляться на ПК, если Telegram Desktop передал user id в Mini App.
- В профиле появилась кнопка «обновить заказы».
- Улучшена карточка товара: кнопка закрытия, превью фотографий, выбор изображения.
- Добавлен просмотр фото в полноэкранном режиме.
- Добавлена иконка корзины в шапку и нижнюю навигацию.
- Кнопка Back в Telegram теперь закрывает фото, карточку товара, экран заказа и только потом возвращает на главную.

После деплоя проверь:

1. Оформить заказ с телефона.
2. Открыть Mini App на ПК через бота, не через обычную ссылку.
3. Перейти в Профиль → обновить заказы.
4. Открыть карточку товара → посмотреть фото → закрыть фото → закрыть карточку.

Важно: синхронизация заказов работает по Telegram ID. Если Telegram Desktop вообще не отдаёт user id в Mini App, то безопасно сопоставить профиль невозможно.
