# План защиты VEAST

## Короткое вступление
VEAST — индивидуальный итоговый комплексный проект по МДК.08.01, МДК.08.02 и МДК.09.01. Формат проекта — коммерческий интернет-магазин одежды в эстетике streetwear / Y2K / techwear. Главная цель сайта — оформление заказа.

## Что показать на защите
1. Открыть главную страницу и объяснить идею VEAST ORBIT DROP.
2. Показать каталог: поиск, фильтры, сортировку, карточки товаров.
3. Открыть карточку товара: фото, размеры, состав, доставка, рекомендации.
4. Добавить товар в корзину.
5. Перейти в корзину, изменить количество, проверить итог.
6. Открыть checkout, показать валидацию формы.
7. Отправить заказ и открыть страницу thanks.
8. Открыть `admin-orders.html` и показать заказ из backend API.
9. Показать `data/orders.json`.
10. Открыть `project.html` и документацию в `docs/`.

## Что сказать про frontend
Сайт реализован на HTML, CSS и JavaScript-модулях. Есть адаптивная вёрстка, каталог, фильтры, сортировка, карточки товаров, корзина, избранное, формы, обработка ошибок и состояния интерфейса.

## Что сказать про backend
Backend написан на Node.js. Он отдаёт статические страницы и API. Главный бизнес-процесс — создание заказа через `POST /api/orders`, серверная валидация и сохранение заказа в `data/orders.json`.

## Что сказать про тестирование
Тестирование запланировано на этапах: бумажный прототип, интерактивный прототип, рабочий сайт. Для полной защиты нужно показать таблицу результатов минимум 5 пользователей и исправления после проверки.

## Финальная фраза
VEAST показывает полный коммерческий путь: пользователь видит коллекцию, выбирает товар, добавляет его в корзину, оформляет заказ, а backend сохраняет результат. Поэтому проект является не просто набором страниц, а рабочим учебным коммерческим веб-продуктом.
